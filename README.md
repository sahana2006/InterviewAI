# AI-Powered Candidate Assessment Platform

A full-stack platform designed to streamline candidate screening through domain-based quizzes, AI-generated interview questions and automated coding evaluations.

## Overview
This system enables recruiters to efficiently assess candidates using dynamic interviews, real-time coding evaluations and an integrated hiring dashboard.

## Features
- Domain-based quizzes tailored to specific job roles
- AI-generated interview questions for adaptive candidate assessment
- Automated coding evaluation with real-time scoring and feedback
- HR dashboard for posting jobs, reviewing applications and managing hiring pipelines
- End-to-end candidate screening workflow

## Tech Stack
- Frontend: React.js
- Backend: Django
- Database: MySQL
- AI/NLP: LLM-based question generation
- Authentication: JWT

## Usage
- Recruiters can create job roles and assign assessments
- Candidates can take quizzes and coding tests
- System evaluates responses and generates feedback
- HR can track applications and manage hiring workflows
